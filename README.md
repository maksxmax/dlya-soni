# Любовная открытка «Для Сонечки» ❤️

Интерактивная открытка-сюрприз: конверт, анимации, галерея фотографий, письмо и скрытые сюрпризы. Сделана на чистых **HTML / CSS / JavaScript** и идеально открывается на **iPhone 16 Pro** в Safari.

---

## 📱 Как открыть на iPhone

**Способ 1 — прямо сейчас (самый простой)**
Открой ссылку сайта в Safari на iPhone → кнопка «Поделиться» → **«На экран „Домой“»**. Откроется как полноэкранное приложение — с вырезом Dynamic Island и без панели Safari.

**Способ 2 — навсегда через GitHub Pages (бесплатно, для ника maksxmax)**
Следуй шагам из раздела «Как выложить на GitHub» внизу README — готовая ссылка:
`https://maksxmax.github.io/dlya-soni/`

**Способ 3 — офлайн**
Можно просто скопировать папку на телефон и открыть `index.html` — всё работает без интернета (фото лежат рядом с сайтом).

---

## 🖼️ Как вставить свои фотографии

1. Положи свои фото в папку `photos/` (формат `.jpg` или `.png`, желательно до ~2 МБ каждое).
2. Открой файл **`js/photos.js`** — там список фотографий:
   ```js
   const PHOTOS = [
     { src: "photos/photo1.jpg", caption: "Наш первый закат вдвоём" },
     { src: "photos/photo2.jpg", caption: "Цветы, как ты любишь" },
     // добавляй сколько угодно строк
   ];
   ```
3. Замени имена файлов и подписи на свои — галерея соберётся сама.
4. Готово ✅

> **Совет:** фото с iPhone снимаются в формате HEIC. Чтобы конвертировать: «Настройки → Камера → Форматы → Наиболее совместимые» (новые фото будут сразу JPG), а старые можно пересохранить через «Поделиться → Сохранить как файл».

## ✏️ Как поменять тексты

- **`index.html`** — заголовки, текст письма, сообщения сюрпризов (блоки `.flip-back`), финал.
- **`css/style.css`** — цвета (в самом верху, блок `:root`) — можно сделать, например, более «золотой» или «розовый» вариант.

---

## 💻 Почему тут нет C#?

C# — **серверная** технология: она выполняется на сервере, а не в браузере телефона. Для любовной открытки сервер не нужен: чистые HTML + CSS + JS открываются мгновенно, работают даже без интернета и не требуют установки чего-либо. Именно так сайт и откроется на iPhone за одну секунду.

---

## ⚡ Что оптимизировано для iPhone 16 Pro

- Учтены **safe-area** (вырез Dynamic Island и нижняя панель) — ничего не обрезается
- Полноэкранные секции на `100svh` — без «прыжков» при скролле
- Кнопки размером 44+ px, тапы без задержек (`touch-action: manipulation`)
- Анимации только на `transform/opacity` — плавные 60–120 fps
- Canvas-частицы ограничены по плотности пикселей и ставятся на паузу в фоне — бережёт батарею
- Фото загружаются лениво (`lazy`) — сайт открывается быстро
- Поддержан режим **«Уменьшить движение»** из настроек iOS
- Работает офлайн, можно добавить на экран «Домой» как приложение

## 🐱 Как выложить на GitHub Pages — по шагам (твой ник: maksxmax)

> **Важно:** бесплатный GitHub Pages работает только с **публичным (Public)** репозиторием — это нормально, сайт будет виден только по твоей ссылке.

### Шаг 1 — создай репозиторий
1. Зайди на GitHub под ником **maksxmax** → https://github.com/login
2. Открой эту ссылку: **https://github.com/new**
3. В поле *Repository name* впиши: **`dlya-soni`**
4. Выбери **Public** ← обязательно!
5. Нажми зелёную кнопку **Create repository**

### Шаг 2 — загрузи файлы сайта
1. Открой эту ссылку: **https://github.com/maksxmax/dlya-soni/upload/main**
2. Перетащи в окно браузера **содержимое** папки `love-card`:
   - `index.html`
   - папку `css`
   - папку `js`
   - папку `photos`
   - `README.md`
3. ⚠️ **Самое важное:** перетаскивай именно *содержимое* папки `love-card`, а не саму папку! `index.html` должен лежать **в корне** (первым уровнем) — иначе сайт не откроется.
4. Нажми зелёную кнопку **Commit changes**

### Шаг 3 — включи GitHub Pages
1. Открой: **https://github.com/maksxmax/dlya-soni/settings/pages**
2. В разделе *Build and deployment* → Source выбери: **Deploy from a branch**
3. Branch выбери: **main**, папка: **/ (root)**
4. Нажми **Save**

### Шаг 4 — готово! 🎉
Через 1–2 минуты сайт откроется по ссылке:

### 👉 https://maksxmax.github.io/dlya-soni/

- Если открылась страница 404 — подожди ещё пару минут и обнови (первый запуск занимает время).
- Статус деплоя видно тут: https://github.com/maksxmax/dlya-soni/actions (должна появиться зелёная галочка ✅).
- На iPhone: открой ссылку в **Safari** → «Поделиться» → **«На экран „Домой“»** — и это будет как приложение.
- Если назвал репозиторий иначе — просто замени `dlya-soni` во всех ссылках на своё имя.
